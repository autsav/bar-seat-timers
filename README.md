# Bar Seat Timers

Timers for the 8 bar seats (B1–B8). Each seat runs a session (60 min by default) and turns
green → yellow → red as time runs down, with sound, vibration and optional browser alerts.

**Live:** https://autsav.github.io/bar-seat-timers/

Features: start / pause / +15 min / end per seat, multi-select bulk actions, guest names and notes,
session history with CSV export, a guest-facing "time remaining" view, light/dark/high-contrast themes,
an optional manager PIN for resets, and keyboard shortcuts (`1`–`8` start or select, `Shift`+`1`–`8` reset,
`R` reset all). Everything is saved in the browser's local storage; it is a single `index.html` with no build step.
